## Regra de aprovação

Uma proposta não é decisão aprovada até que seu status e a aprovação responsável estejam registrados. Decisões relevantes devem declarar contexto, alternativas, vantagens, riscos, consequências e critérios de validação. A stack do MVP web está aprovada. Backend, banco remoto e integrações continuam pendentes de requisitos e decisões próprias.
