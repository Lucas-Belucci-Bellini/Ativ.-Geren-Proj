## Regra de aprovação

Uma proposta não é decisão aprovada até que seu status e a aprovação responsável estejam registrados. Decisões relevantes devem declarar contexto, alternativas, vantagens, riscos, consequências e critérios de validação. Não iniciar a implementação principal enquanto a escolha da stack permanecer pendente.
